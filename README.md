# AskMe — сервис «Вопросы и ответы»

Учебный проект курса **VK Education / Web**. Сервис позволяет пользователям задавать вопросы
и получать на них ответы, голосовать за вопросы и ответы, отмечать правильные решения.

Образец для подражания — [Stack Overflow](https://stackoverflow.com).

## Статус

- **ДЗ 1** — статическая вёрстка (этот репозиторий).
  Сделаны страницы: `base.html`, `index.html`, `question.html`.
- Остальные страницы (`ask.html`, `login.html`, `signup.html`, `profile.html`) —
  в следующих домашних заданиях.

## Как открыть вёрстку

Проект на текущем этапе — **чистый статический HTML**, сервер или сборка не нужны.
Достаточно браузера.

### Способ 1. Просто открыть файл

Открой в браузере файл:

```
hw_1/public/index.html
```

(двойной клик по файлу в проводнике, либо `Ctrl+O` в браузере). Все стили, скрипты и
картинки подключаются относительно — вёрстка работает и по `file://`.

### Способ 2. Локальный HTTP-сервер (рекомендуется)

Ближе к реальной работе (все пути и статика резолвятся как на боевом сервере):

```bash
cd hw_1/public
python3 -m http.server 8000
```

Затем открой в браузере:

```
http://localhost:8000/index.html
```

## Структура репозитория

```
web/
├── .gitignore
├── README.md
└── hw_1/
    └── public/
        ├── base.html
        ├── index.html
        ├── question.html
        ├── ask.html          # заглушка
        ├── login.html        # заглушка
        ├── signup.html       # заглушка
        └── static/
            ├── css/          # Bootstrap 5.3 (локально) + style.css
            ├── js/           # Bootstrap JS (локально) + main.js
            └── img/          # favicon, аватарки, иконки лайков
```

Вся статика хранится **локально в проекте** и подключается **без CDN**:

- Bootstrap CSS и собственные стили — `hw_1/public/static/css/`;
- Bootstrap JS и собственные скрипты — `hw_1/public/static/js/`;
- изображения, аватарки, иконки — `hw_1/public/static/img/`.

## Технологии

- **HTML5** — разметка страниц;
- **CSS3** — собственные стили (`style.css`);
- **Bootstrap 5.3** — сетка и базовые компоненты (локальная копия);
- **JavaScript (ванильный)** — голосование (3 состояния), переключение «правильного ответа».

## Что реализовано в вёрстке

- **Общий layout** — шапка (логотип → главная, поиск, кнопка «Задать вопрос», юзерблок),
  центральная колонка + правая колонка (`Популярные теги`, `Лучшие пользователи`),
  footer, прижатый к низу окна.
- **Карточка вопроса** — аватар, заголовок-ссылка, текст, теги, число ответов, время,
  виджет лайков (три состояния: лайк / дизлайк / ничего).
- **Пагинация** вопросов и ответов с активной страницей.
- **Правильный ответ** — два состояния виджета + подсветка отмеченного ответа.
- **Адаптив** — корректная перестройка на ширинах ≈1200 / 768 / 375 px.
- **Favicon** и осмысленные `title` на каждой странице.
