Как в Django вывести связанные объекты в шаблоне?

Есть две модели: Question (вопрос) и Answer (ответ). Ответ связан с вопросом через ForeignKey. В шаблоне question.html я вывожу вопрос и хочу показать список всех ответов на него. Сейчас делаю примерно так: 

{% for question in questions %}
    <h2>{{ question.title }}</h2>
    {% for answer in question.answer_set.all %}
        <p>{{ answer.text }}</p>
    {% endfor %}
{% endfor %}

Проблема в том, что для каждого вопроса выполняется отдельный запрос к базе (проблема N+1), и при большом количестве вопросов страница грузится очень долго. Как вывести связанные объекты одним запросом?

Это классическая проблема N+1. Она решается с помощью select_related() (для связи «к одному») и prefetch_related() (для связи «ко многим»). В вашем случае подойдёт prefetch_related: 

from django.shortcuts import render
from .models import Question

def index(request):
    questions = Question.objects.prefetch_related('answer_set').all()
    return render(request, 'index.html', {'questions': questions})

После этого Django выполнит ровно два запроса: один для вопросов и один для всех связанных ответов.
